# IT-Park: HTML & CSS Advanced - Project #6 (test-6)

This project was developed as part of the "Frontend Development" course at IT-Park. 
It showcases advanced CSS techniques, UI/UX design principles, and interactive 
elements beyond basic HTML.

## 🛠 Technologies Used
* `HTML5` — For the semantic structure of the page.
* `CSS3` — For complex styling, including gradients and depth (`box-shadow`).
* `Interactivity` — Hover effects and transition cues for enhanced User Experience.

## 📝 Project Features
As seen in the preview, this project includes:

* `Modern UI`: Dark-themed cards set against a vibrant cyan/blue gradient background.
* `Styled Lists`: Service lists utilizing custom check-mark icons.
* `Interactive Elements`: Buttons and `Slide out` features for user engagement.
* `Clean Layout`: Centered card design with smooth borders and professional typography.
